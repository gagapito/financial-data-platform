# Financial Data Platform

A simulated end-to-end fintech data engineering system that models banking transactions, ETL pipelines, and analytics for fraud detection and risk scoring.

## Features
- Synthetic banking data generator
- ETL pipeline (extract, transform, load)
- PostgreSQL data warehouse
- Fraud detection logic
- Customer risk scoring analytics
