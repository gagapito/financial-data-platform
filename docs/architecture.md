# Financial Data Platform

## Overview
This project simulates a real-world fintech data system that processes banking transactions, builds a data warehouse, and generates fraud/risk analytics.

## System Architecture

Data Generator
    ↓
Raw CSV Files
    ↓
ETL Pipeline
    ↓
PostgreSQL Warehouse
    ↓
Analytics Layer
    ↓
Dashboard

## Tech Stack
- Python (data generation + ETL)
- PostgreSQL (data warehouse)
- SQL (analytics layer)
- React (dashboard optional)
- Pandas (data processing)

## Key Features
- Synthetic banking transaction generation
- ETL pipeline for cleaning and loading data
- Star schema data warehouse
- Fraud detection logic
- Customer risk scoring system
